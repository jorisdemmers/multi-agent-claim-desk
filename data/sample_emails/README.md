# Sample claim emails

Invented claim emails in different file formats, to try the upload option in the notebook (Step 6, the trigger: *my own email: upload*).

| File | Format | Policy | What happens? |
|---|---|---|---|
| `sample_1_burst_pipe.eml` | email file (Gmail, Apple Mail, Thunderbird) | DH-1001 | A burst pipe. Is it covered? |
| `sample_2_burglary.docx` | Word document | DH-2002 | A burglary. Is it covered? |
| `sample_3_old_roof.pdf` | PDF | DH-1001 | A leaking old roof. Is it covered? |
| `sample_4_vague.html` | web page (HTML) | none | A vague email. Where does the chain stop? |

To download a file: click on it, then click the download button (↓) at the top right.

You can also upload your own email: a .txt, .eml, .msg (Outlook), .pdf, .docx or .html file. Use invented emails only. In real mode, the text is sent to OpenAI.

All people and claims in these files are invented. The addresses use example.com, a domain reserved for examples.
